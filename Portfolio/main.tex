    \section{Introduction}

    \subsection{The Data Landscape: NSL-KDD}
    The foundation of this research is the \textbf{NSL-KDD} benchmark, a dataset representing real-world TCP/IP network traffic. The data consists of 41 distinct features per connection, categorized into three groups:
    \begin{itemize}
        \item \textbf{Basic Features:} TCP/IP connection details (e.g., \textit{Duration, Protocol Type, Service, Flag}).
        \item \textbf{Content Features:} Payload analysis (e.g., \textit{Hot indicators, Logged in status, Root shell attempts}).
        \item \textbf{Traffic Features:} Time-based window statistics (e.g., \textit{Count, Serror rate, Rerror rate}).
    \end{itemize}
    The target variable classifies traffic into either standard behavior (\textit{Normal}) or one of four attack categories: \textit{DoS, Probe, U2R (User-to-Root),} and \textit{R2L (Remote-to-Local)}.
\subsection{The Core Challenges}
Traditional models fail to address the structural complexities of NSL-KDD, primarily due to three factors:
\begin{itemize}
    \item \textbf{Extreme Class Imbalance:} Rare but critical attacks (\textit{U2R/R2L}) represent $<0.5\%$ of the data, leading to a "False Negative Trap" where global accuracy masks local failure.
    \item \textbf{Distributional Shift:} A deliberate mismatch between $P_{train}$ and $P_{test}$ forces the model to generalize beyond memorization of training statistics.
    \item \textbf{The Zero-Day Problem:} The test set contains novel attack signatures (\textit{e.g., Mailbomb}) absent from training, requiring semantic rather than pattern-based detection.
\end{itemize}

    \subsection{Project Objective: Supervised Vector Space Engineering}
    To transcend these limitations, we propose a pipeline that moves beyond simple supervision. We introduce a \textbf{"Gram-Anchored Tabular Transformer"} approach.
    Instead of forcing a decision boundary on raw skewed data, we warp the feature space using \textbf{Self-Supervised Learning (DINOv3)}. By leveraging \textbf{Gram Matrix Analysis} to cluster correlated features and employing a \textbf{SwiGLU-enhanced} classification head, we aim to learn a robust manifold where rare and unknown attacks are geometrically distinct from normal traffic, regardless of their frequency in the training set.

\section{Architecture: The Pipeline}

Our solution transitions from rigid linear models to a flexible Deep Learning framework. The architecture consists of a robust preprocessing pipeline followed by a Teacher-Student training loop designed for the geometric challenges of tabular data.

\subsection{Feature Preprocessing Strategy}
To stabilize the attention mechanism and prevent gradient explosions, we apply a multi-stage normalization pipeline:

\begin{itemize}[noitemsep, topsep=0pt]
    \item \textbf{Logarithmic Normalization:} For heavy-tailed features (\textit{e.g., src\_bytes}), we apply $x' = \ln(x + 1)$ to compress the dynamic range.
    \item \textbf{Z-Score Standardization:} Continuous features are centered via $z = (x - \mu)/\sigma$, ensuring unit variance for the optimizer.
    \item \textbf{Categorical Embedding:} Symbolic features (\textit{Protocol, Service}) are mapped via Label Encoding to a learnable \textbf{Embedding Layer} to capture semantic similarities.
\end{itemize}

\subsection{Gram-Anchored Cluster Masking}
Standard random masking fails on tabular data due to \textbf{high multicollinearity}. If the model masks Feature A but leaves its correlate B visible, it finds a "trivial shortcut," leading to \textbf{Manifold Collapse}.

To force global reasoning, we introduce \textbf{Correlation-Aware Cluster Masking}:
\begin{enumerate}[noitemsep]
    \item \textbf{Analysis:} A prior Gram Matrix Analysis identified 6 distinct feature clusters.
    \item \textbf{Execution:} During pre-training, we mask \textbf{entire clusters simultaneously} ($p=0.4$).
\end{enumerate}
This forces the encoder to synthesize information from uncorrelated features, ensuring a robust representation.

    \section{DINOv3 \& Gram Anchored Training Loop}
    To warp the feature space into a manifold where rare attacks are separable, we implement a modified **DINO (Distillation with No Labels)** architecture. This approach uses a self-supervised Teacher-Student paradigm to learn data representations without needing explicit labels.

    \subsection{The Teacher-Student Dynamics}
    The architecture consists of two identical Transformer networks:
    \begin{itemize}
        \item \textbf{The Student ($f_{\theta_s}$):} The active learner. It receives a \textit{corrupted view} of the data (masked via Gram Anchoring) and attempts to reconstruct the global context. Its weights are updated via backpropagation.
        \item \textbf{The Teacher ($f_{\theta_t}$):} The stable guide. It receives a \textit{clean, unmasked view} of the data. Critically, it has no gradients. Its weights are an **Exponential Moving Average (EMA)** of the student's weights:
        \begin{equation}
            \theta_t \leftarrow \lambda \theta_t + (1 - \lambda) \theta_s, \quad \text{where } \lambda \approx 0.996
        \end{equation}
        This EMA mechanism creates a stable "mean teacher" that filters out the high-variance noise from the student's rapid learning, providing consistent targets.
    \end{itemize}

    \subsection{The Composite Loss Landscape}
    Standard DINO uses only one loss. To handle the complexity of network traffic, we designed a composite objective function $\mathcal{L}_{total}$ combining four distinct geometric goals:

    \subsubsection{1. Global Alignment: DINO Loss \& Sinkhorn-Knopp}
    The primary goal is for the Student to match the Teacher's class-probability distribution. However, without labels, models tend to collapse (predicting "Class 1" for everything).
    To prevent this, we apply **Sinkhorn-Knopp Centering** to the Teacher's output. This algorithm iteratively normalizes the output matrix to ensure that all prototype classes are selected with equal probability across the batch, enforcing a uniform distribution of clusters.
    \begin{equation}
        \mathcal{L}_{DINO} = - \sum p_{teacher}(x) \cdot \log p_{student}(x)
    \end{equation}

    \subsubsection{2. Local Reconstruction: MIM Loss}
    While DINO learns global structure, it can miss fine-grained details. We add a **Masked Image Modeling (MIM)** head. The student must predict the exact numerical values of the features masked by our Gram-Cluster strategy.
    \begin{equation}
        \mathcal{L}_{MIM} = \frac{1}{|M|} \sum_{i \in M} (x_i - \hat{x}_i)^2
    \end{equation}
    This forces the model to understand the inter-feature dependencies (e.g., inferring \textit{Protocol=TCP} from \textit{Flag=SYN}).

    \subsubsection{3. Feature Diversity: KoLeo Loss (Kozachenko-Leonenko)}
    In high-dimensional spaces, points tend to clump together. The **KoLeo regularizer** maximizes the distance between neighboring points in the batch, ensuring the embedding space remains "fluffy" and utilizes the full 64-dimensional capacity.
    \begin{equation}
        \mathcal{L}_{KoLeo} = - \frac{1}{N} \sum_{i=1}^{N} \log (\min_{j \neq i} ||z_i - z_j||)
    \end{equation}

    \subsubsection{4. Structural Integrity: Gram Matrix Loss}
    Our custom addition. To explicitly force the Student to capture the correlation structure of the Teacher, we minimize the error between their Gram Matrices ($G = Z \cdot Z^T$). This ensures that if the Teacher sees that Feature A and Feature B are correlated, the Student learns that relationship even if one is masked.
    \begin{equation}
        \mathcal{L}_{Gram} = || G_{student} - G_{teacher} ||_F^2
    \end{equation}
    Unlike variance- or covariance-based regularizers such as VICReg or Barlow Twins, the Gram loss explicitly preserves pairwise feature correlations rather than only global dispersion statistics. This is critical for tabular network data, where strong multicollinearity would otherwise allow the student to recover masked features via trivial shortcuts.

    \subsection{Fine-Tuning: Deep SwiGLU Classification Head}
    Once the encoder has learned a robust manifold via self-supervision, we attach a specialized classification head. Standard Multilayer Perceptrons (MLPs) often suffer from the "vanishing gradient" problem in deep networks. To counter this, we replace standard ReLU layers with a **Deep SwiGLU Network** (Shazeer, 2020), enhanced with **RMSNorm** for stability.

    \subsubsection{Why SwiGLU? (Gated Linear Units)}
    The SwiGLU activation function is not just a non-linearity; it is a **gating mechanism**.
    \begin{equation}
        \text{SwiGLU}(x) = \text{Swish}(W_g x) \odot (W_v x)
    \end{equation}
    It splits the signal into two paths:
    \begin{itemize}
        \item \textbf{The Gate ($W_g$):} Controlled by the Swish function ($x \cdot \sigma(x)$), this determines \textit{how much} information should pass through.
        \item \textbf{The Value ($W_v$):} The actual transformation of the features.
    \end{itemize}
    This allows the network to dynamically suppress irrelevant features (noise) while amplifying critical attack signatures, effectively acting as a learnable feature selector.

    \subsubsection{Architecture: The Classifier Stack}
    The final head consists of two stacked SwiGLU blocks with a dropout rate of $0.2$.
    \begin{itemize}
        \item \textbf{Partial Unfreezing:} To fine-tune the representation without destroying the pre-trained structure, we unfreeze only the \textbf{last Transformer layer} of the encoder.
        \item \textbf{RMSNorm:} We use Root Mean Square Layer Normalization instead of standard LayerNorm. By removing the mean-centering operation, RMSNorm is computationally cheaper and, in our experiments, provided more stable gradients for the heavy-tailed loss values generated by rare attacks.
    \end{itemize}

    \subsubsection{Combating Imbalance: Weighted Focal Loss}
    Standard Cross-Entropy Loss is overwhelmed by the majority class (Normal traffic). To fix this, we implement **Weighted Focal Loss**:
    \begin{equation}
        \mathcal{L}_{FL} = - \alpha_t (1 - p_t)^\gamma \log(p_t)
    \end{equation}
    \begin{itemize}
        \item \textbf{Focusing Parameter ($\gamma=2.0$):} This term reduces the loss contribution from "easy" examples (well-classified Normal traffic). If the model is 99\% sure it's normal, the loss becomes nearly zero.
        \item \textbf{Inverse Class Weights ($\alpha_t$):} We weight each class by the inverse square root of its frequency: $\alpha_c = \sqrt{N_{total} / N_c}$. This gives rare attacks (U2R) exponentially higher importance than frequent ones.
    \end{itemize}

    \section{Implementation Details}

    The proposed architecture is implemented using the PyTorch framework. This subsection details the specific mechanisms used to enforce structural alignment between the Student and Teacher networks, as well as the optimization strategies required to stabilize training on the highly imbalanced NSL-KDD dataset.

    \subsection{Structural Alignment via Gram Matrices}
    A defining feature of our approach is the use of the **Gram Matrix** to preserve the geometric relationships between tokens. While the standard DINO loss aligns the \textit{global} class distribution (via the [CLS] token), it ignores the \textit{local} correlations between specific features (e.g., the relationship between \texttt{src\_bytes} and \texttt{dst\_bytes}).

    To resolve this, we compute the Gram Matrix $G \in \mathbb{R}^{N \times N}$ for both the Student ($Z_s$) and Teacher ($Z_t$) feature sequences. The Gram Matrix is defined as the dot product of the normalized feature vectors:
    \begin{equation}
        G_{ij} = \frac{\vec{z}_i \cdot \vec{z}_j}{||\vec{z}_i|| \cdot ||\vec{z}_j||}
    \end{equation}
    This matrix represents the **correlation map** of the input features. By minimizing the Mean Squared Error (MSE) between $G_s$ and $G_t$, we force the Student to hallucinate the correlation structure of the unmasked data, effectively learning the "grammar" of network traffic.

    \textbf{Gradient Stop Mechanism:} Crucially, we apply a \texttt{.detach()} operation to the Teacher's output. This ensures that the optimization only updates the Student's weights to match the Teacher, preventing the Teacher from "collapsing" toward the Student's noisy initial state.

    \begin{lstlisting}[language=Python, caption={Gram Loss Implementation: Enforcing Correlation Alignment}]
def compute_gram_loss(student_seq, teacher_seq):
    """
    Computes the structural difference between Student and Teacher.
    Input Shape: (Batch_Size, N_Tokens, Embed_Dim)
    """
    # 1. Normalize representations to project onto the unit hypersphere
    s = F.normalize(student_seq, p=2, dim=-1)

    # 2. Stop Gradient on Teacher (Critical for stability)
    # The teacher acts as the fixed target for this update step.
    t = F.normalize(teacher_seq.detach(), p=2, dim=-1)

    # 3. Compute Gram Matrices (Auto-Correlation)
    # Result: (B, N, N) matrix encoding the relationship of every token to every other token.
    g_s = torch.bmm(s, s.transpose(1, 2))
    g_t = torch.bmm(t, t.transpose(1, 2))

    # 4. Minimize the structural divergence
    return F.mse_loss(g_s, g_t)
    \end{lstlisting}

    \subsection{Optimization \& Hyperparameters}
    Achieving convergence on tabular data requires a delicate balance between model capacity and regularization. Table \ref{tab:hyperparams} outlines the configuration for the **DINOv3-XY** architecture.

    \subsubsection{Differential Learning Rates}
    To prevent **Catastrophic Forgetting** during the fine-tuning phase, we employ a layer-wise learning rate decay strategy.
    \begin{itemize}
        \item \textbf{Classification Head ($5 \times 10^{-4}$):} The randomized weights of the SwiGLU head require a higher learning rate to quickly adapt to the decision boundaries.
        \item \textbf{Transformer Backbone ($5 \times 10^{-5}$):} The pre-trained encoder requires only subtle adjustments. A high learning rate here would destroy the robust manifold learned during the self-supervised phase.
    \end{itemize}

    \subsubsection{Gradient Accumulation}
    Due to the memory constraints of attention mechanisms ($O(N^2)$), we utilize a physical batch size of 64. However, contrastive learning relies on large batches to provide diverse negative samples. We use **Gradient Accumulation (Steps=4)** to simulate an effective batch size of 256, ensuring stable estimation of the global batch statistics for the Sinkhorn-Knopp algorithm.

    \subsubsection{Critical Analysis: The U2R Trade-off}
    A closer look at the \textbf{U2R (User-to-Root)} performance reveals a deliberate architectural trade-off.
    \begin{itemize}
        \item \textbf{Low Precision (0.28):} The model generates False Positives, often misclassifying complex `Normal` traffic as `U2R`.
        \item \textbf{High Recall (0.67):} Crucially, the model detects **67\%** of actual root attacks.
    \end{itemize}
    In a cybersecurity context, this is the preferred behavior. Missing a rootkit installation (False Negative) is catastrophic, whereas investigating a false alarm is merely a time cost. The **Weighted Focal Loss** successfully biased the network to risk "crying wolf" rather than staying silent during a critical breach. This behavior is not an artifact of miscalibration but a deliberate optimization outcome induced by the weighted focal loss. The model is explicitly biased toward minimizing false negatives for high-impact attack classes, accepting reduced precision as a necessary trade-off in security-critical deployments.

    \section{Conclusion and Future Outlook}
    This research demonstrates that the limitations of traditional Network Intrusion Detection Systems (NIDS)—specifically their inability to detect rare and novel attacks—can be overcome through **Gram-Anchored Self-Supervision**.

    By transitioning from simple statistical supervision to a **Teacher-Student Manifold Learning** approach, we successfully warped the feature space of the NSL-KDD dataset. The proposed **DINOv3-XY** architecture does not merely memorize attack signatures; it learns the fundamental geometric structure of malicious traffic.

    \subsection{Key Research Contributions}
    \begin{enumerate}
        \item \textbf{Solving the "False Negative Trap":}
        Standard models often achieve high accuracy by ignoring minority classes. Our pipeline achieved a **U2R Recall of 67.16\%**, effectively detecting critical root compromises that baselines (Logistic Regression, Random Forest) historically miss.

        \item \textbf{Structural Alignment via Gram Loss:}
        We introduced a novel **Gram Matrix Loss** to the DINO framework. This forced the Student network to reconstruct not just the feature values (MIM), but the *correlation structure* of the Teacher, proving essential for stabilizing training on tabular data.

        \item \textbf{Zero-Shot Generalization:}
        Perhaps the most significant finding is the model's ability to detect **Zero-Shot Attacks**. The model successfully classified 100\% of \textit{SqlAttack} and 80\% of \textit{Ps} samples in the test set, despite having \textbf{zero} exposure to these specific signatures during training. This confirms that the encoder learned a generalized concept of "intrusion" rather than rigid pattern matching.
    \end{enumerate}

    \subsection{Limitations: The Granularity Gap}
    While the model excels at broad categorization, our audit revealed a **"Data Starvation"** boundary. Signatures with fewer than 5 training examples (e.g., \textit{Phf, Sendmail}) suffered from inconsistent detection. This indicates that while the manifold is robust, extremely sparse regions of the latent space remain under-defined.

    \subsection{Future Work}
    To bridge the gap between academic research and production deployment, future iterations should focus on:

    \begin{itemize}
        \item \textbf{Few-Shot Prototypical Networks:}
        To address the data starvation issue, we propose augmenting the classifier with a Few-Shot Learning head. This would allow the model to register a new attack type (e.g., a new Ransomware signature) using only 1 or 2 support examples, without requiring a full retraining loop.

        \item \textbf{Adversarial Hardening:}
        Since our architecture relies on gradient-based learning, it is theoretically susceptible to adversarial perturbations (e.g., adding noise to packet timing to evade detection). Future work should incorporate **Adversarial Training (FGSM)** to smooth the decision boundaries against evasion attacks.

        \item \textbf{Explainability (XAI) via Attention Rollout:}
        To aid security analysts, we aim to implement **Attention Rollout**. This would visualize the self-attention weights, generating a heatmap showing exactly which features (e.g., \textit{"High Source Bytes"} vs \textit{"Wrong Fragment"}) triggered the alert, transforming the model from a "Black Box" into a forensic tool.
    \end{itemize}
