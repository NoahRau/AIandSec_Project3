\chapter{Introduction}

\section{The Cyber Security Challenge}
Modern network infrastructures face an evolving landscape of cyber threats. Traditional Intrusion Detection Systems (IDS) often rely on signature-based methods or shallow machine learning models (like Logistic Regression), which struggle with:
\begin{enumerate}
    \item \textbf{Zero-Day Attacks:} Detecting novel attack vectors not seen during training.
    \item \textbf{Extreme Class Imbalance:} In the NSL-KDD dataset, critical attacks like \textit{User-to-Root (U2R)} and \textit{Remote-to-Local (R2L)} represent less than 1\% of the traffic, leading to "Zero Recall" in standard models.
\end{enumerate}

\section{Project Objective}
This project introduces a **"Supervised Vector Space Engineering"** pipeline. Instead of simple classification, we warp the feature space using **Self-Supervised Learning (DINO)** and **Gram Matrix Analysis** to maximize the separation between normal traffic and rare anomalies. The final classification is performed by a Deep Neural Network enhanced with **SwiGLU activations**.

\chapter{Architecture: DINO & Gram Anchoring}

To learn robust features from imbalanced data, we implemented a Teacher-Student architecture inspired by DINO (Self-Distillation with No Labels), adapted for tabular data.

\section{The Pipeline Overview}
The system operates in two phases:
1.  **Pre-Training (Self-Supervised):** The model learns the structure of network traffic without labels using a masked autoencoder approach and metric learning.
2.  **Fine-Tuning (Supervised):** A specialized SwiGLU head is trained on the frozen features to classify the 5 categories (Normal, DoS, Probe, U2R, R2L).

\section{SwiGLU Classification Head}
For the final classification, we replace standard ReLU layers with **SwiGLU** (Swish-Gated Linear Unit). This gating mechanism allows the network to dynamically select relevant features, which is crucial for distinguishing subtle U2R attacks from normal traffic.

\chapter{Implementation Code}

The implementation utilizes PyTorch. Below is the core logic for the DINO Loss and the Gram Matrix Loss integration.

\begin{lstlisting}[language=Python, caption=Dinov3 Loss Implementation]
class DINOLoss(nn.Module):
    def __init__(self, out_dim, teacher_temp=0.04, student_temp=0.1):
        super().__init__()
        self.student_temp = student_temp
        self.teacher_temp = teacher_temp
        self.center = nn.Parameter(torch.zeros(1, out_dim), requires_grad=False)

    def forward(self, student_output, teacher_output):
        # Teacher sharpening
        t_out = F.softmax((teacher_output - self.center) / self.teacher_temp, dim=-1)
        t_out = t_out.detach() # Stop gradient
        
        # Student log-softmax
        s_out = F.log_softmax(student_output / self.student_temp, dim=-1)
        
        return -torch.sum(t_out * s_out, dim=-1).mean()

def compute_gram_loss(student_seq, teacher_seq):
    # Calculate feature correlations (Gram Matrix)
    s = F.normalize(student_seq, p=2, dim=-1)
    t = F.normalize(teacher_seq.detach(), p=2, dim=-1)
    
    g_s = torch.bmm(s, s.transpose(1, 2))
    g_t = torch.bmm(t, t.transpose(1, 2))
    
    return F.mse_loss(g_s, g_t)
\end{lstlisting}

The implementation achieved a robust **83.53\% multiclass accuracy**, proving that Deep Learning architectures can outperform traditional statistical methods in cybersecurity domains.
