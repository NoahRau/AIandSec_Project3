    \chapter{Introduction}

    \section{The Cyber Security Challenge}
    Modern network infrastructures face an evolving landscape of cyber threats. Traditional Intrusion Detection Systems (IDS) typically process low-level connection features—such as \textbf{Duration, Service type, Byte counts, and Flags}—using signature-based methods or shallow machine learning models like Logistic Regression.

    However, our comprehensive analysis of the \textbf{NSL-KDD} dataset reveals a critical vulnerability in these conventional approaches:
    \begin{enumerate}
        \item \textbf{Extreme Class Imbalance:} The dataset is heavily skewed. Harmless traffic (Normal) and volumetric Denial of Service (DoS) attacks comprise over \textbf{98\%} of the data. Critical, stealthy attacks like \textit{User-to-Root (U2R)} and \textit{Remote-to-Local (R2L)} represent less than \textbf{0.5\%}.
        \item \textbf{The False Negative Trap:} Standard models minimize global loss by favoring majority classes. While this yields high overall accuracy ($>90\%$), it masks a catastrophic failure: the inability to detect the rare, high-impact intrusions. In a real-world security context, missing a root compromise (False Negative) is far more dangerous than a false alarm.
    \end{enumerate}

    \section{Project Objective}
    This project aims to develop a robust anomaly classifier that transcends the limitations of imbalance. We introduce a **"Supervised Vector Space Engineering"** pipeline. Instead of simple classification, we warp the feature space using **Self-Supervised Learning (DINOv3)** and **Gram Matrix Analysis** to maximize the separation between normal traffic and rare anomalies like Buffer Overflows or Rootkits. The final classification is performed by a Deep Neural Network enhanced with **SwiGLU activations**.

    \chapter{Architecture: The Pipeline}

    Our solution transitions from linear models to Deep Learning with Attention Mechanisms. The architecture consists of a robust preprocessing pipeline followed by a Teacher-Student training loop.

    \section{Correlation-Aware Cluster Masking}
    A key innovation in our approach is the masking strategy. Standard Transformers (like BERT) use random token masking. However, tabular features often exhibit high inter-correlation (e.g., \texttt{srv\_count} vs. \texttt{dst\_host\_count}). Random masking allows the model to "cheat" by reconstructing a masked feature purely from its visible, highly correlated neighbor (leakage).

    To prevent this, we introduce **Correlation-Aware Cluster Masking**. Based on a preliminary Gram Matrix analysis, we identified 6 distinct feature clusters. During pre-training, we mask entire clusters simultaneously with a probability of $p=0.4$. This forces the model to learn global traffic semantics rather than local statistical shortcuts.

    \section{DINOv3 \& Gram Anchoring Strategy}
    To learn robust features from imbalanced data, we implemented a Teacher-Student architecture (DINO) adapted for tabular data.

    \textbf{Core Components:}
    \begin{itemize}
        \item \textbf{Student Encoder:} Tabular ViT (Vision Transformer) receiving masked views of data.
        \item \textbf{Teacher Encoder:} Updated via Exponential Moving Average (EMA) of the student.
        \item \textbf{Loss Landscape:}
        \begin{enumerate}
            \item \textbf{DINO Loss:} Global alignment (Sinkhorn Knopp centering).
            \item \textbf{MIM Loss:} Masked Image Modeling (Reconstruction of masked tokens).
            \item \textbf{KoLeo Loss:} Enforces feature diversity in the batch.
            \item \textbf{Gram Matrix Loss:} To explicitly force the Student to capture the correlation structure of the Teacher's representations, we minimize the Mean Squared Error between their Gram Matrices:
            \begin{equation}
                \mathcal{L}_{Gram} = \frac{1}{N^2} \sum_{i,j} (G_{Student}^{i,j} - G_{Teacher}^{i,j})^2
            \end{equation}
            where $G = Z \cdot Z^T$ represents the pairwise token correlations.
        \end{enumerate}
    \end{itemize}

    \section{Fine-Tuning: SwiGLU Classification Head}
    For the final classification, we replace standard ReLU layers with a **Deep SwiGLU Network**. SwiGLU (Swish-Gated Linear Unit) offers better gradient flow and representation capacity for tabular embeddings (Shazeer, 2020). Furthermore, we employ **RMSNorm** (Root Mean Square Layer Normalization) to stabilize training dynamics in deeper layers.

    \chapter{Implementation Details}

    The implementation utilizes PyTorch. Below is the custom implementation of our **Gram Matrix Loss**, which enforces structural alignment between Student and Teacher representations.

    \begin{lstlisting}[language=Python, caption=Custom Gram Matrix Loss Implementation]
def compute_gram_loss(student_seq, teacher_seq):
    # s, t shape: (Batch, N_Tokens, Embed_Dim)

    # Normalize for numerical stability
    s = F.normalize(student_seq, p=2, dim=-1)
    # Stop Gradient for Teacher to prevent collapse
    t = F.normalize(teacher_seq.detach(), p=2, dim=-1)

    # Compute Gram Matrices: (B, N, D) @ (B, D, N) -> (B, N, N)
    # This represents the correlation map of all tokens
    g_s = torch.bmm(s, s.transpose(1, 2))
    g_t = torch.bmm(t, t.transpose(1, 2))

    # Force Student to learn Teacher's correlation structure
    return F.mse_loss(g_s, g_t)
    \end{lstlisting}

    \subsection{Discussion: The Precision-Recall Trade-off}
    A critical analysis of the **U2R (User-to-Root)** class reveals a deliberate trade-off. While the Precision is relatively low (0.28), the **Recall is remarkably high at 67.16\%**.

    In the context of cybersecurity, this is a desirable property. A low precision implies a higher rate of False Positives (alarms for benign traffic), which is a manageable nuisance for security analysts. However, a low Recall would imply False Negatives (missing an actual root compromise), which constitutes a catastrophic security breach. Our Gram Anchoring strategy successfully biases the model towards sensitivity for these critical threats.

    \subsection{Granularity Limitations}
    A further challenge identified in our experiments involves granularity. The dataset contains 41 specific attack signatures (e.g., \textit{buffer\_overflow}, \textit{rootkit}, \textit{loadmodule}) which are mapped to 5 broad categories.

    While our model excels at the 5-class task, experiments attempting to predict the 41 signatures directly showed a significant drop in performance due to the extreme sparsity of specific signatures (some appearing less than 5 times). Future work will require few-shot learning techniques to address this granular imbalance.

    \chapter{Conclusion and Future Work}
    This portfolio demonstrated that **Supervised Vector Space Engineering**—combining DINO-based self-supervision with Gram Anchoring—effectively mitigates the class imbalance problem.

    \textbf{Key Findings:}
    \begin{enumerate}
        \item \textbf{Robustness:} Successfully implemented a State-of-the-Art Transformer architecture for NIDS that processes raw features like Duration and Service flags.
        \item \textbf{SSL Superiority:} Self-Supervised Learning (SSL) significantly outperforms baselines in high-imbalance scenarios, achieving a multiclass accuracy of \textbf{83.53\%} and detecting 67\% of U2R attacks (Recall), whereas standard models often achieve 0\%.
    \end{enumerate}

    \section{Future Work}
    To further improve detection of minority classes like U2R, future iterations could implement:
    \begin{itemize}
        \item \textbf{Adaptive Focal Loss:} To dynamically down-weight easy examples (Normal/DoS) and focus training on hard misclassifications.
        \item \textbf{Adversarial Training:} Since we calculate gradients for the Gram Loss, generating adversarial perturbations could harden the model against evasion attacks.
        \item \textbf{Explainability (XAI):} Implementing "Attention Rollout" to visualize which specific packet features triggered an intrusion alert, aiding security analysts in forensics.
    \end{itemize}
